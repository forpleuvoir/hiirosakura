# HiiroSakura 使用文档

HiiroSakura 是一个客户端增强模组：它不添加新方块或新物品，而是把游戏里几十个「原版用起来别扭」的地方变得顺手——比如一眼看清手上物品的附魔、一键带动一排门、把常用操作挂到轮盘或快捷键上。

| 项目 | 说明 |
|---|---|
| 模组版本 | `4.0.0+alpha` |
| 游戏版本 | Minecraft `26.2` |
| 加载器 | Fabric、NeoForge |
| 运行侧 | 仅客户端，服务端不需要安装 |
| 前置模组 | [IbukiGourd](https://modrinth.com/mod/ibukigourd) |

> **所有功能默认都是关闭的**。装好模组后不会改变任何游戏行为，需要你进入设置界面自己开启。

## 打开设置界面

- 游戏内按下 **H + S**（可以改绑）。
- 或者从 ModMenu（Fabric）/ 模组列表（NeoForge）里点本模组的配置按钮。

界面按页签组织，重开时会回到你上次停留的页签：

| 页签 | 里面有什么 |
|---|---|
| Hiiro Sakura 设置 | 模组全部开关，分为「额外信息渲染」「游戏玩法」「聊天消息」三组 |
| 任务管理器 | 自定义任务：到点自动发消息 / 发指令 / 跑脚本 |
| 自定义径向菜单 | 自己做的轮盘菜单，按键弹出，用来快速执行任务 |
| 事件订阅管理器 | 指定事件发生时自动做点什么 |
| 物品编辑器 | 编辑带数据组件的物品（**进入世界后才会出现**） |

## 文件都在哪

都在游戏目录的 `config` 下：

| 内容 | 路径 |
|---|---|
| 模组设置 | `config/hiirosakura/config.yml` |
| 任务 | `config/hiirosakura/data/task_manager.json` |
| 事件订阅 | `config/hiirosakura/data/event_manager.json` |
| 物品编辑器列表 | `config/hiirosakura/data/item_stack_manager.json` |
| 自定义轮盘菜单 | `config/hiirosakura/custom_radial_menu/<菜单名>.json` |

配置在启动时读取、退出游戏时保存；按 ESC 打开游戏菜单时若有改动也会顺手保存。设置文件里与默认值相同的项不会写进去，所以文件通常很短，可以直接手改。

## 默认快捷键

| 快捷键 | 默认值 | 作用 |
|---|---|---|
| 打开主界面 | `H + S` | 打开 HiiroSakura 设置界面 |
| 连锁开门触发键 | `左 Shift` | 配合连锁规则里的「按键响应模式」使用 |

其余快捷键（烟花快捷使用、相机切换、轮盘菜单、快捷执行轮盘、各功能开关的切换键、任务快捷键）默认**都没有绑定**，需要你在界面里自行录制。

## 怎么读这些文档

- 每篇开头是「什么时候你会想用它」，中间是操作步骤，**配置项表格统一放在每篇末尾**，当查阅用。
- 表格里的「界面位置」写成 `游戏玩法 → 连锁开门 → 启用` 这样的路径，照着点就能找到；「配置键」是 `config.yml` 里的实际键名，手改配置时用得上。
- 「开关 + 快捷键」类条目在界面上一行内是「开关」+「组合键设置」：直接点开关就能启停，也可以录一个按键，之后按键切换并在屏幕上提示「开 / 关」。

## 关于本文档

内容按当前源码与锁定版本的依赖（IbukiGourd `1.0.0-alpha`、Nebula `0.4.0`）逐项整理，**未做游戏内实测**，界面文案与渲染细节以实际表现为准。

脚本接口中少数方法有实现层面的限制（例如脚本不能创建对象、不能把脚本函数传给 Java 的 `Runnable` / `Predicate`），文档中已在对应位置标注。
