# 聊天消息

三个互相独立的聊天工具：把不关心的消息**挡掉**、发送前**改写**消息内容、把聊天做成玩家头顶的**气泡**。

入口：**H + S → 聊天消息**。

---

## 聊天消息过滤

**什么时候用**：服务器刷屏的广告、组队频道里重复的提示、某些机器人消息，不想让它们占据聊天栏。

**怎么用**

1. 打开 `聊天消息 → 聊天消息过滤 → 启用`。
2. 点「过滤器映射」，逐条加入正则表达式，一条一行。
3. 消息**完整匹配**某条正则时就会被丢掉。规则里没写 `.*` 之类的通配，就是要求整句完全一致，所以通常要写成 `.*关键词.*` 这种形式。

**效果范围**：被过滤的消息既不会进入聊天栏，也不会生成聊天气泡。它作用于**你接收到的消息**，不影响你发送的内容。

---

## 聊天消息注入

**什么时候用**：想让发出的每条消息自动带上前缀 / 后缀、自动补全某个固定格式，比如发言必须先发一句 `[组队]`。

**怎么用**

1. 打开 `聊天消息 → 聊天消息注入 → 启用`。
2. 在「注入映射」里维护「过滤器（正则表达式）→ 消息表达式」的对应关系。默认是一条 `.*` → `#{message}`，意思是不做任何改动。
3. 想给所有消息加前缀，就把表达式改成 `[前缀] #{message}`。

**匹配规则**

- 要求整条消息**完整匹配**正则。
- **自上而下**取第一条命中的条目，命中后就不再继续匹配——所以特殊情况要放在前面，通用规则放在最后。
- `#{message}` 是原始消息的占位符，出现几次就替换几次；表达式里的其它内容原样输出。

只对聊天消息生效，以 `/` 开头的指令不会被改写。

---

## 聊天气泡

**什么时候用**：想在玩家头顶看到谁说了什么，而不是一直盯着左下角聊天栏。

**怎么用**

1. 打开 `聊天消息 → 聊天气泡 → 启用`。
2. 消息能正确解析出「谁说的」才会显示气泡，这一步靠「服务器配置」里的「解析表达式」。默认规则是 `<玩家名> 消息内容` 这种格式，很多服务器并不一样，需要按你所在服务器的聊天格式调整。
3. 外观相关的项都有现成的默认值，一般不用动：气泡颜色、文字颜色、持续时间（默认 10 秒）、淡入淡出时间、最大宽度、缩放、位置偏移。

**解析表达式怎么写**

它是一个正则，**必须包含名为 `name` 和 `message` 的分组**，分别对应玩家名与消息内容。默认值是：

```
<(?<name>[^>]+)>\s(?<message>.+)
```

对应 `<Steve> 你好` 这样的消息。如果你的服务器是 `[VIP] Steve: 你好` 这种格式，就要写成像 `\[.*?\]\s*(?<name>\w+):\s*(?<message>.+)` 这样的表达式。

不想自己写？[让 AI 帮你写解析表达式](chat-bubble-regex-prompt.md)——把提示词复制给 AI、贴上你服务器的聊天原文即可。

如果消息里的玩家名不能直接匹配到玩家，可以打开条目里的两个附加开关：

| 开关 | 说明 |
|---|---|
| UUID | 尝试用消息附带的 UUID 匹配玩家。不过配置说明指出：大多数服务器把聊天当系统消息发送，并不会附带 UUID |
| 玩家档案 | 尝试用消息附带的玩家档案匹配玩家，说明同上 |

**服务器配置怎么选**

- 每个服务器一条配置，用服务器名区分；单人游戏对应内置的 **`#single`**。
- 界面上是卡片网格，可以新增、改名、拖拽排序。
- 消息解析用的是**部分匹配**（只要能在消息里找到符合格式的一段就算命中），解析失败的消息不会生成气泡。
- 玩家必须存在于客户端玩家列表、且没有隐身，才会看到气泡。
- 同一个玩家同时只显示最后一条消息的气泡。
- 解析前会先去掉消息里的 `§` 颜色代码，所以带颜色的服务器消息也能正常识别。

## 配置项速查

### 聊天消息过滤

| 界面位置 | 配置键 | 默认值 | 说明 |
|---|---|---|---|
| 启用 | `chat.chat_filter.enable` | 关闭 | — |
| 过滤器映射 | `chat.chat_filter.filter_mapping` | 空 | 每条为正则，整句匹配则过滤 |

### 聊天消息注入

| 界面位置 | 配置键 | 默认值 | 说明 |
|---|---|---|---|
| 启用 | `chat.chat_inject.enable` | 关闭 | — |
| 注入映射 | `chat.chat_inject.inject_mapping` | `.*` → `#{message}` | 过滤器（正则）+ 消息表达式，自上而下取第一条 |

### 聊天气泡

| 界面位置 | 配置键 | 默认值 | 取值范围 |
|---|---|---|---|
| 启用 | `chat.chat_bubble.enable` | 关闭 | — |
| 仅Y轴旋转 | `...chat_bubble.only_y_rotation` | 开启 | — |
| 位置偏移量 | `...chat_bubble.offset` | `(0, 0)` | `(-10,-1) ~ (10,10)` |
| 缩放 | `...chat_bubble.scale` | `(1, 1)` | `(0.1,0.1) ~ (10,10)` |
| 使用最高亮度 | `...chat_bubble.use_max_light` | 关闭 | — |
| 最大宽度 | `...chat_bubble.max_width` | `120` | `9 ~ 480` |
| 纹理颜色 | `...chat_bubble.texture_color` | `#FF8899` | 颜色 |
| 文本颜色 | `...chat_bubble.text_color` | `#FFFFFF` | 颜色 |
| 持续时间 | `...chat_bubble.duration` | `10 秒` | `0 ~ 60 秒` |
| 淡入持续时间 | `...chat_bubble.fade_in_duration` | `0.25 秒` | `0 ~ 2 秒` |
| 淡出持续时间 | `...chat_bubble.fade_out_duration` | `0.25 秒` | `0 ~ 2 秒` |
| 服务器配置 | `...chat_bubble.server_chat_bubble_config` | `#single` 一条 | 每条含解析表达式、UUID、玩家档案 |
| └ 解析表达式 | `<服务器名>.regex` | `<(?<name>[^>]+)>\s(?<message>.+)` | 必须含 `name` 与 `message` 分组 |
| └ UUID | `<服务器名>.enable_uuid` | 关闭 | — |
| └ 玩家档案 | `<服务器名>.enable_profile` | 关闭 | — |
