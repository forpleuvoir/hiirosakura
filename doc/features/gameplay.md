# 游戏玩法

这里的开关都是「让你少点几下、少出错」这一类：开一排门、收完自动补种、落地自动换回胸甲……大多只需要打开开关，个别需要先配一条规则。

入口：**H + S → 游戏玩法**。

---

## 自动复活

**什么时候用**：在刷怪塔、虚空、岩浆里反复死亡时，原版每次都要看死亡界面再点一次重生。

打开 `游戏玩法 → 自动复活` 即可。之后死亡不再显示死亡界面，会直接完成重生（重生流程本身还是原版的，由服务端处理）。

---

## 连锁开门

**什么时候用**：开一扇双开门要左右各点一次；一片装饰用的活板门要一格一格点。开启后右键一次就会带动周围符合条件的门一起开关。

**怎么用**

1. 打开 `游戏玩法 → 连锁开门 → 启用连锁`。
2. 默认已经带了两条规则，通常直接就能用：
   - **普通门 / 木门**：默认就启用。按住 **左 Shift** 时临时禁用连锁（想只开一扇门时用）。
   - **活板门（不含铁活板门）**：默认是**禁用**状态，**按住左 Shift 点活板门**才触发连锁。
3. 想改成「按键才启用」或反过来，改规则里的「按键响应模式」；配合的按键就是上面那条「触发快捷键」（默认左 Shift，可改）。
4. 需要自己的规则时，点「连锁规则」右侧按钮，用卡片形式新增：分别指定「触发方块」和「连锁方块」（都用方块匹配器），再选策略。

**两种连锁策略怎么选**

- **邻域扫描**：以点击位置为中心，在一个范围里找方块，**不要求方块之间相连**。适合「同一片区域里的同类方块一起动」，比如一格一格排开的装饰门。可调「搜索半径」（1 ~ 5）、「搜索形状」（球形按直线距离找 / 立方体按方块坐标范围找）。
- **链式扩散**：只沿着**物理相连**的方块向外扩散，只要互相接触或属于同一扇门就会传递。适合长走廊上一整排连着的门。

两种策略都建议保留默认的「严格同类方块」和「状态对齐」：前者只影响和点击方块完全相同的方块，后者只影响当前开关状态相反的那些（也就是不该被重复点的那半边）。

**注意**

- 单次最多带动「连锁上限」个方块（范围 1 ~ 32，默认普通门 1、活板门 8）。
- 超出交互距离的方块会被自动跳过。
- 处理连锁期间再点门会被忽略，不会叠加触发。

## 方块破坏保护

**什么时候用**：怕手滑挖掉紫水晶母岩、家门口的装饰方块，或者不想误挖某些机器。

**怎么用**

1. 打开 `游戏玩法 → 方块破坏保护 → 启用`。
2. 点「方块匹配器」那一行的铅笔按钮，按卡片新增条目：给它起个名字，配「方块匹配」和「物品匹配」。
3. 两个条件**同时成立**才会拦截：比如默认自带的一条就是「方块 = 紫水晶母岩，物品 = 任意」，等于不管手上拿什么都不能挖它。
4. 想限制「只有用某种镐挖才拦」，就把物品匹配设成对应物品。

被拦下时会弹出「由方块破坏保护阻止的操作 -> 条目名」，挖掘过程中会持续拦截。

## 物品使用拦截

**什么时候用**：准星对着某些方块时不想让某个物品被用掉，例如对着箱子时别把手里的东西用出去、防止在特定方块上误放末影珍珠。

**怎么用**：打开 `物品使用拦截 → 启用`，在「物品匹配器」里新增一条：配「方块匹配」+「物品匹配」，两者同时命中才拦截。

被拦下时提示「由物品使用拦截阻止的操作 -> 条目名」。注意准星没对着方块时按空气处理，所以只配方块条件而不管物品的话，平时也不会误拦。

---

## 物品丢弃拦截

**什么时候用**：`Q` 手滑把关键物品丢进岩浆、把任务物品丢给别的玩家。

**怎么用**：打开 `物品丢弃拦截 → 启用`，在「物品匹配器」里新增条目，配好不该被丢掉的物品。

- 覆盖的丢弃方式包括：手持物品的丢弃键（默认 `Q`）、背包和容器界面里的丢弃、把物品拖到界面外、创造模式物品栏里的丢弃与拖出。
- 被拦下时提示「由物品丢弃拦截阻止的操作 -> 条目名」。
- 配置说明里明确写了：**不能保证拦住所有丢弃方式**，别把它当成唯一保险。

## 滑翔辅助

**什么时候用**：滑翔时想按一个键就加速，而不是在手忙脚乱中翻快捷栏找烟花；或者滑翔时不想让手里的烟花被「用」到方块 / 生物身上。

**滑翔时禁用烟花火箭交互**

打开 `游戏玩法 → 滑翔 → 滑翔时禁用烟花火箭交互`。之后滑翔中手持烟花右键，只会用于加速，不会再触发对实体或方块的交互。

**滑翔时快捷使用烟花火箭**

1. 给 `滑翔 → 滑翔时快捷使用烟花火箭` 录一个顺手的按键（默认没绑定）。
2. 滑翔中按这个键，模组会自己找一件可用的烟花：主手有就直接用，其次副手；都没有就从物品栏里找——在快捷栏里会切换选中槽，在背包其它格子会换到当前快捷栏，用完后换回原来的槽位。
3. 找不到可用烟花时什么都不会发生。

**注意——默认匹配器认得哪些烟花**

「烟花」匹配器只有一个**脚本条目（包含模式）**，脚本的条件是「物品带有 fireworks 组件、飞行时间大于 0、且没有任何爆炸效果」，因此：

| 你手上的烟花 | 会不会被识别 |
|---|---|
| 只有飞行时间、**没有**爆炸效果（常见的纯加速烟花） | **会** |
| 带爆炸效果的烟花 | 不会 |
| 不是烟花火箭、没有 fireworks 组件、飞行时间为 0 | 不会 |

也就是说，默认配置下**快捷使用只认纯飞行的加速烟花**。如果你也想让带爆炸效果的烟花被识别，把那个脚本条目的模式从「包含」改成「排除」——注意排除模式会让「不是烟花火箭」的物品也一并命中，所以建议同时再加一条「匹配类型 = 烟花火箭」的条目。

## 自动切换鞘翅

**什么时候用**：跳下高地时自动穿上鞘翅，落地后又自动换回胸甲，不用手动换装备。

**怎么用**

1. 打开 `游戏玩法 → 自动切换鞘翅 → 启用`。
2. 确认「装备槽」是你想要的位置，默认「胸甲」。
3. 按需调整「可切换的滑翔器」和「可切换的装备」：前者默认是鞘翅（判断依据是物品带 `minecraft:glider` 组件），后者默认是六种胸甲。

工作方式：当你尝试开始滑翔失败、并且不在地面、双手不忙、不在水下、也不是创造飞行时，会从物品栏里找出滑翔器并装备上，然后立刻重试一次滑翔；当你没在滑翔时，会把鞘翅换回匹配「可切换的装备」的物品。取物同样是副手优先，其次在快捷栏里切换，否则从背包换到快捷栏，用完换回原槽位。

## 自动补种

**什么时候用**：收农作物时想收完立刻补上种子，不用切物品、不用重新对准耕地。

**怎么用**

1. 打开 `游戏玩法 → 自动补种 → 启用`。
2. 默认已经配好了 5 条映射，开箱即用：小麦 → 小麦种子、胡萝卜 → 胡萝卜、马铃薯 → 马铃薯、甜菜根 → 甜菜种子、下界疣 → 下界疣，地面方块分别是耕地和灵魂沙。
3. 要加自己的作物，点「映射」那一行的按钮，新增一张卡片，填「目标方块」「补种物品」「地面方块」三项。

原理是：破坏方块的下一刻，对该方块**下方方块的上表面**右键一次，交互时会自动切换到物品栏里对应的物品，交互完再切回去。

**注意**

- 只在自己挖掉方块时触发，别人挖不算。
- 每条映射要求「目标方块」和「地面方块」同时命中，按列表顺序取第一条命中的。
- 物品栏里没有对应的补种物品时不会补种。

## 相机切换器

**什么时候用**：想看自己角色的样子、想从别的玩家或生物的视角看周围。

**怎么用**

1. 给 `游戏玩法 → 相机切换器 → 快捷键` 录一个按键（默认没绑定）。
2. 准星对着某个实体时按键 → 相机切到该实体；没有对着实体时按键 → 切回自己。
3. 想切相机后避免误操作，打开「阻断玩家操作」：相机不在自己身上时，攻击、选取方块、使用物品、破坏方块都会被拦下。

也可以直接用命令：

| 命令 | 作用 |
|---|---|
| `/hs:camera_switch <目标>` | 切到指定实体，目标写成 `名字[UUID]` 的形式（有 Tab 补全），找不到会提示 `entity not found` |
| `/hs:camera_switch reset` | 切回自己 |

切换和阻断都是纯客户端行为，不会给服务端发任何东西。

## 音效过滤

**什么时候用**：某些音效很吵或者干扰听声辨位，比如农场里牲畜的叫声、某些机器的循环音。

**怎么用**

1. 打开 `游戏玩法 → 音效过滤 → 启用`。
2. 点「音效过滤映射」那一行的按钮，新增条目，在条目里选择要静音的音效——条目框左端可以直接试听，确认选对了再加。
3. 支持增删和拖拽排序。

**注意**

- 按音效 ID 精确匹配。
- 被过滤的音效在声音引擎入口就被拦下，因此**也不会出现在字幕里**。
- 新增条目默认是空音效，不选具体音效的话不会过滤任何东西。

---

## 创造模式下选取玩家获取头颅

**什么时候用**：存档里想要别的玩家的头颅做装饰。

打开 `H + S → 创造模式下选取玩家时获取头颅`，然后在创造模式下对着那名玩家按选取键（默认鼠标中键），头颅会直接出现在你的快捷栏。

## 配置项速查

| 界面位置 | 配置键 | 默认值 | 说明 |
|---|---|---|---|
| 自动复活 | `gameplay.auto_rebirth` | 关闭 | 死亡不显示死亡界面，直接重生 |
| 连锁开门 → 启用连锁 | `gameplay.chain_doors.enable` | 关闭 | — |
| 连锁开门 → 触发快捷键 | `...chain_doors.activation_key` | 左 Shift | 配合「按键响应模式」 |
| 连锁开门 → 连锁规则 | `...chain_doors.rules` | 2 条 | 见下表 |
| 方块破坏保护 → 启用 | `gameplay.block_break_protection.enable` | 关闭 | — |
| 方块破坏保护 → 方块匹配器 | `...block_break_protection.matcher` | 1 条 | 名称 `Budding Amethyst`，方块=紫水晶母岩，物品=任意 |
| 物品使用拦截 → 启用 | `gameplay.item_use_intercept.enable` | 关闭 | — |
| 物品使用拦截 → 物品匹配器 | `...item_use_intercept.matcher` | 空 | 方块匹配 + 物品匹配 |
| 物品丢弃拦截 → 启用 | `gameplay.item_drop_intercept.enable` | 关闭 | — |
| 物品丢弃拦截 → 物品匹配器 | `...item_drop_intercept.matcher` | 空 | 命中则不丢弃 |
| 滑翔 → 禁用烟花火箭交互 | `gameplay.gliding.disable_firework_rocket_interaction_when_gliding` | 关闭 | — |
| 滑翔 → 快捷使用烟花火箭 | `...gliding.quick_use_firework_rocket__when_gliding` | 未绑定按键 | 注意键名里是两个下划线 |
| 滑翔 → 烟花 | `...gliding.firework_matcher` | 只识别纯飞行烟花（有飞行时间、无爆炸效果） | 物品匹配器 |
| 自动切换鞘翅 → 启用 | `gameplay.auto_switch_elytra.enable` | 关闭 | — |

| 自动补种 → 启用 | `gameplay.auto_replant.enable` | 关闭 | — |

| 相机切换器 → 快捷键 | `gameplay.camera_switcher.shortcut_key` | 未绑定 | 切到准星所指实体，没有则切回自己 |
| 相机切换器 → 阻断玩家操作 | `...camera_switcher.block_player_actions` | 关闭 | — |
| 音效过滤 → 启用 | `gameplay.sound_event_filter.enable` | 关闭 | — |
| 音效过滤 → 音效过滤映射 | `...sound_event_filter.filter_mapping` | 空 | 按音效 ID 精确匹配 |
| 创造模式下选取玩家时获取头颅 | `pick_player_head_on_creative` | 关闭 | 在设置首页，不在游戏玩法组里 |

### 连锁规则字段

| 字段 | 中文名 | 含义 |
|---|---|---|
| `originDoor` | 触发方块匹配 | 点击哪些方块时启动连锁 |
| `chainDoor` | 连锁方块匹配 | 哪些方块会被一起操作 |
| `keyToggleMode` | 按键响应模式 | 关闭 = 平时启用、按住触发键禁用；开启 = 平时禁用、按住触发键启用 |
| `strategy` | 连锁策略 | 邻域扫描 / 链式扩散 |
| `radius` | 搜索半径（邻域扫描） | `1 ~ 5`，默认 `1` |
| `shape` | 搜索形状（邻域扫描） | 球形 / 立方体，默认立方体 |
| `sameBlock` | 严格同类方块 | 默认开启 |
| `syncState` | 状态对齐 | 默认开启，只影响状态相反的那些方块 |
| `limit` | 连锁上限 | `1 ~ 32`，邻域扫描默认 `1`、链式扩散默认 `8` |
