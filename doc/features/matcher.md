# 匹配器

「匹配器」是各个功能共用的条件组件，用来回答一个问题：**这件物品 / 这个方块，算不算符合条件？**

它不是独立功能，而是给下面这些功能当条件用的：

| 用在哪 | 匹配什么 |
|---|---|
| [连锁开门](gameplay.md#连锁开门) | 每条规则的「触发方块」「连锁方块」 |
| [方块破坏保护](gameplay.md#方块破坏保护) | 「方块匹配」+「物品匹配」 |
| [物品使用拦截](gameplay.md#物品使用拦截) | 「方块匹配」+「物品匹配」 |
| [物品丢弃拦截](gameplay.md#物品丢弃拦截) | 物品匹配 |
| [滑翔](gameplay.md#滑翔辅助) → 烟花 | 物品匹配 |
| [自动切换鞘翅](gameplay.md#自动切换鞘翅) | 物品匹配（可切换的装备 / 滑翔器） |
| [自动补种](gameplay.md#自动补种) | 目标方块、地面方块、补种物品 |

---

## 怎么编辑

1. 进入用到匹配器的那一行配置，点右侧的铅笔按钮，打开编辑浮层。
2. 浮层里逐条添加匹配项，每项按需要填参数；左上角切换**组合模式**，每个条目自己还能选「包含 / 排除」。
3. 右上角的播放按钮可以就地测试：
   - **物品匹配器**：用你**当前手持的物品**测试（手上没东西时不显示这个按钮）。
   - **方块匹配器**：用你**准星指向的方块**测试（没对着方块时不显示）。
   - 结果显示「测试通过」或「测试失败」。
4. 旁边还有导出（把匹配器 JSON 复制到剪贴板）和导入（从文本读回来）。**导入会整体替换**当前的组合模式与全部条目，不会合并。

---

## 组合模式怎么用

组合模式决定整体怎么算：

| 模式 | 含义 | 典型用法 |
|---|---|---|
| 全部匹配 | 所有条目都成立才通过 | 同时限定类型 + 标签 + 状态 |
| 任意匹配 | 任意一条成立就通过 | 「这些物品都算」，逐条列物品 |
| 黑名单 | 所有条目都不成立才通过 | 「除了这些以外都算」 |

每个条目还能单独选「包含」或「排除」：

- **包含**：条件为真才算通过。
- **排除**：条件为假才算通过。常用来在「任意匹配」里排除某个特例（例如「所有活板门，但铁活板门除外」）。

**边界行为**：条目列表为空时，「任意匹配」永远不通过，「全部匹配 / 黑名单」永远通过。

列表上方会显示摘要：0 项显示「无」，1 项直接显示那一项，多项显示「组合模式：N个匹配项」。

## 物品匹配器的条目

| 条目 | 判断什么 | 要填的参数 |
|---|---|---|
| 内嵌匹配器 | 引用另一个完整匹配器（只在顶层添加菜单里可选，避免无限嵌套） | 一个完整匹配器 |
| 匹配类型 | 物品类型相同 | 物品 |
| 匹配名称 | 物品显示名按正则整串匹配 | 正则表达式 |
| 匹配脚本 | 用脚本判断 | 脚本，变量 `itemStack`、`result` |
| 匹配数量 | 数量落在范围内 | 整数范围 |
| 匹配稀有度 | 稀有度相同 | 稀有度（常见 / 少见 / 稀有 / 史诗） |
| 匹配附魔 | 指定附魔的等级落在范围内 | 附魔 ID、等级范围 |
| 匹配标签 | 物品带有该标签 | 物品标签 |
| 匹配组件 | 物品带有该数据组件 | 数据组件类型 |

新增条目时的默认值会取自你**当前的状态**，方便快速配置：新建「匹配类型」默认就是你手持物品的类型，「匹配附魔」默认取手持物品的第一个附魔，等等；手上没有物品时用兜底值（例如西瓜、`1..64`）。

---

## 方块匹配器的条目

| 条目 | 判断什么 | 要填的参数 |
|---|---|---|
| 内嵌匹配器 | 引用另一个完整方块匹配器（同样只在顶层可选） | 一个完整方块匹配器 |
| 匹配类型 | 方块类型相同 | 方块 |
| 匹配脚本 | 用脚本判断 | 脚本，变量 `blockResult`、`blockState`、`blockPos`、`result` |
| 匹配位置 | 坐标落在包围盒范围内 | 最小 / 最大坐标 |
| 匹配标签 | 方块状态带有该标签 | 方块标签 |
| 匹配属性 | 方块状态的某个属性等于某个值 | 属性名与取值 |

同样地，新增条目时的默认值取自你准星指向的方块（包括它的第一个标签和第一个属性），没有目标方块时用兜底值。

---

## 写匹配脚本

匹配脚本拿到的变量因匹配器而异，**只要调用 `result.set(true)` 就表示匹配成功**：

```javascript
// 物品匹配器：名字里带「剑」的才算
if(itemStack.getName().contains("剑")){ result.set(true); }
```

默认的脚本内容是一段只含注释的模板，改掉注释写自己的逻辑即可。

---

## 注意事项

- 「匹配名称」用的是正则**整串匹配**，写 `剑` 只能匹配名字正好是「剑」的物品，想模糊匹配要写 `.*剑.*`。
- 匹配脚本会对**每一个被匹配的对象**执行一次。在掉落物很多、方块很多的功能里（例如连锁开门的连锁方块）会反复调用，脚本尽量写简单些。
- 导入匹配器是整体替换，操作前确认当前配置是否还需要。
- 默认已经配好的匹配器一般能直接用，改之前建议先导出备份一份。

## 关于嵌套

「内嵌匹配器」只在**顶层**的添加菜单里提供，进入内嵌匹配器后就不再提供，所以实际上最多只有一层嵌套，不用担心配出无限递归的结构。

## 脚本条目的限制

匹配脚本和其他脚本共用同一套运行环境和权限（不能创建对象、只能访问限定包、必须传全参数），详见 [脚本](script.md)。匹配器脚本里记得用 `result.set(true)` 表示命中。
