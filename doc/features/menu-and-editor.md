# 菜单与物品编辑

这一篇讲两个「自己动手」的部分：把常用任务收到一个轮盘里随手触发（[自定义径向菜单](#自定义径向菜单)），以及在创造模式里做出带自定义名称、Lore、附魔、属性的物品（[物品编辑器](#物品编辑器)）。

---

# 自定义径向菜单

**什么时候用**：任务变多以后，一个个记快捷键很累。做成轮盘后，按住一个键弹出圆盘，鼠标一甩就能执行对应任务。

轮盘里的任务与任务管理器里的任务互相独立，但可以把任务管理器里的任务复制过来，不用重写一遍。

入口：**H + S → 自定义径向菜单**。

## 创建一个菜单

1. 左列顶部点「添加菜单项」，填一个名字，录一个快捷键（想更细可以点旁边的扩展设置：按键环境、触发时机、是否严格匹配等），保存。
2. 名字的规则：去掉首尾空白后不能为空；不能包含 `\ / : * ? " < > |`；不能是 `.` 或 `..`；不能与已有菜单重名。
3. 菜单出现后，右列工具栏第一个按钮是它的快捷键，第二个是快捷键的扩展设置，随时可以改。

## 往里加任务

- 点工具栏的「新建任务」，填法和任务管理器里的任务一样（名称、图标、执行时间、执行器类型与内容），确认后追加到当前菜单。
- 任务列表支持拖拽排序，每行右侧是「执行」「编辑」「删除」；任何改动都会立刻保存。

### 从任务管理器导入任务

点工具栏的「从任务管理器导入任务」，会弹出任务管理器里的任务列表。勾选需要的（可多选）并确认，这些任务会被**复制**进当前菜单——复制的是名称、设置、执行时间、执行器与图标，不含任务管理器里绑定的独立快捷键。

导入是复制而不是引用，所以之后再改任务管理器里的原件不会影响已经导入的副本；重复导入会产生重复项。

## 打开轮盘后怎么操作

按下该菜单的快捷键就会弹出轮盘，操作方式和快捷任务执行界面一致：

| 操作 | 效果 |
|---|---|
| 左键点扇区 | 执行该任务并关闭界面 |
| 中键点扇区 | 删除该任务（需确认） |
| 右键点扇区 | 编辑该任务 |
| 右键点空选区 | 新建任务 |
| 右键点中心或环外 | 关闭界面 |

任务多于「每页最大任务数量」时会自动分页。

## 外观设置

每个菜单可以在「菜单设置」里单独调整外观，默认值已经可用：

| 设置项 | 默认值 | 范围 |
|---|---|---|
| 轮盘内径渐变色 | `#33000000` | 颜色 |
| 轮盘外径渐变色 | `#7F000000` | 颜色 |
| 选中项轮盘内径渐变色 | `#33FF8899` | 颜色 |
| 选中项轮盘外径渐变色 | `#FFFF8899` | 颜色 |
| 未选中边框颜色 | `#33FFFFFF` | 颜色 |
| 选中边框颜色 | `#FFFF8899` | 颜色 |
| 图标缩放 | `1.3` | `0.2 ~ 2.0` |
| 轮盘内半径 | `180` | `80 ~ 250` |
| 轮盘外半径 | `460` | `200 ~ 500` |
| 选项渲染半径 | `320` | `150 ~ 400` |
| 间距 | `12` | `0 ~ 30` |
| 每页最大任务数量 | `8` | `4 ~ 12` |
| 圆角半径 | `4` | `0 ~ 20` |
| 边框宽度 | `2` | `0 ~ 10` |
| 倾斜角度 | `4` | `0 ~ 20` |

内半径必须小于外半径，否则无法确认保存。

## 删除与文件

- 每个菜单右侧有「删除」，需要二次确认；删除时会同时注销快捷键并删掉对应文件。
- 保存位置：`config/hiirosakura/custom_radial_menu/<菜单名>.json`，一个菜单一个文件，与默认值相同的设置不会写进去。
- **菜单名就是文件名**，所以受限字符不可用、也不能重名。
- 保存时会重写这个目录下的 `.json` 文件，**不要**把其它功能的 JSON 放在这个目录里。

# 物品编辑器

**什么时候用**：想在创造模式里做一把带自定义名称、Lore、附魔、属性修饰符的物品；或者想拼一条 `/give` 指令发给别人。

入口：**H + S → 物品编辑器**。注意这个页签**只有进入世界 / 服务器后才会出现**。

## 添加一个物品

列表页有三种新增方式：

| 方式 | 说明 |
|---|---|
| 以手持物品为基础添加 | 主手或副手拿着东西时才出现，直接以它为模板打开编辑界面 |
| 添加 | 用一个默认物品（西瓜）作为模板新建 |
| 编辑（铅笔按钮） | 修改列表里已有的条目 |

列表还支持拖拽排序、删除（需二次确认，按住快速动作键——默认左 Shift——可跳过确认）。

## 编辑界面

- **物品预览**：鼠标悬停会显示原版提示框，效果和游戏里一致。
- **物品类型**：点图标打开物品浏览器，按创造模式分类页签浏览，也可以搜索（支持显示名与注册名）。
- **物品数量**：范围从 `1` 到该物品的最大堆叠数（默认 64，改了「最大堆叠数」组件后会跟着变）。
- **添加组件**：下拉里是所有数据组件，可以按注册名或翻译名搜索。

组件列表里，**已适配**的组件（名称用主题主色显示）点开是专门为它做的编辑界面，比如自定义名称、Lore、附魔、属性修饰符、食物、可装备、工具、武器等，直接填就行。

**未适配**的组件（名称用辅色显示）点开是通用编辑器：先选根类型（对象 / 数组 / 字符串 / 布尔 / 整数 / 长整数 / 浮点 / 双精度 / 字节 / 短整数 / 空），再按序列化结构逐层填。确认时才会按该组件的编解码器解析，**解析失败只会报错、不会写入**，所以不用担心填错把物品弄坏。按住快速动作键（默认左 Shift）可以直接改整份 JSON，适合熟悉格式的人快速粘贴。

**集合型字段**（例如「可修复」里的物品列表）支持三种取值来源：

- **从注册表获取**：按注册表逐条挑选添加（物品、方块、实体、状态效果、伤害类型等）。
- **从标签选择**：选一个标签，把该标签下的条目一次性全部加入。
- **从资源管理器获取**：在可装备组件的装备模型选择里出现，选中后自动把命名空间与路径填回字段。

## 把物品拿到手里

| 方式 | 说明 |
|---|---|
| 获取到背包 | **仅创造模式**出现；把物品放进背包并同步给服务端，成功时提示「已将物品[x]添加到背包」 |
| 复制为指令 | 生成 `/give @p <物品注册名>[<组件>] <数量>` 复制到剪贴板并弹窗显示，可以直接粘贴到聊天栏执行 |

## 限制与说明

- 同一个组件不能重复添加，重复添加会提示「组件[x]已存在」。
- 未适配组件需要手写序列化数据，格式错误会提示且不写入。
- 这份列表保存在 `config/hiirosakura/data/item_stack_manager.json`：打开页签时载入，离开页签时如果有改动就写回。
- **只做拖拽排序不会标记为已改动**，所以一次会话里如果只调整了顺序，离开时不会写回文件。
- 目前只有这个界面自己读写这份列表，对外输出靠「获取到背包」和「复制为指令」两种方式。
- 读取时单条解析失败只记录日志并跳过该条，不会影响其它条目。
