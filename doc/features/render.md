# 渲染增强

这一组功能只改客户端的显示方式，不改变世界里的任何东西：让该看见的看得见（物品信息、引信倒计时），让不想看见的不出现（侧边计分板、文本乱码）。

入口：**H + S → 额外信息渲染**。

---

## 手持物品信息

**什么时候用**：手上拿着附魔书、潜影盒、成书这类物品时，原版只在屏幕中间飘一个名字，想知道里面是什么还得按 `F3 + H` 再逐一悬停。这个功能把手持物品的详细信息直接摊在屏幕上。

**怎么用**

1. `H + S → 额外信息渲染 → 手持物品信息`，打开「启用」。原版的手持物品名称显示会被它接管。
2. 在同组的「物品信息」里逐项勾选你想看到的内容。默认只开三项：物品名称、数量、`tooltip_display`。
3. 位置不合适时，调「渲染位置偏移」和「行距」；想要底色可以调「文本背景颜色」「背景颜色」。

**选条目的小提示**

- 附魔、Lore、容器内容、旗帜图案、成书内容、药水信息、盔甲纹饰、耐久等条目默认都是关的，需要什么勾什么。
- `damage`（损坏值）、`item_id`（注册名）、`component_count`（组件数量）这三项还要求游戏开启「高级物品提示」（`F3 + H`），否则不会出现。
- 条目过多时信息会堆得很高，建议只开常用的几项。

**进阶：按物品内容动态决定显示什么**

「脚本」条目可以按当前物品临时改写上面任意条目的开关。比如只在物品数量小于 16 时隐藏数量：

```javascript
if(itemStack.getCount() < 16){ renderState["count"] = false; }
```

`renderState["<条目名>"] = true/false` 里设置过的条目优先生效，没设置的按配置值。注意每次渲染都会执行一次脚本，条目多、掉落物多的时候会有性能开销，配置里的红字提示就是在说这件事。

## 掉落物实体信息渲染

**什么时候用**：刷怪塔下方、多人服务器地面上散落一堆掉落物，想不开背包就看清每个是什么、有多少；或者在经验农场里想知道每颗经验球值多少经验。

**怎么用**

1. `H + S → 额外信息渲染 → 掉落物实体信息渲染`，打开「启用」。
2. 「物品信息」子组里勾选要显示的内容——选项和手持物品信息**完全一样**，两处各自独立保存，需要分别设置。
3. 「经验球经验值」单独控制要不要在经验球上显示数值。
4. 距离太远的掉落物不显示，用「渲染距离」调整。

**注意**

- 「渲染距离」源码里是按**与相机距离的平方**比较的，默认值 233 实际相当于约 15 格，想让远处掉落物也显示需要把数字调得大很多（上限 2333，约 48 格）。
- 「文本描边色」在界面上是红字标注的：开启后可能有严重的性能问题。
- 「文本显示模式」可选「正常 / 穿透 / 多边形偏移」，穿墙能看见时用「穿透」。

## TNT 与苦力怕引信提示

**什么时候用**：想知道眼前这颗 TNT 还剩多久爆炸、苦力怕膨胀到什么程度了，用进度条或数字代替凭感觉。

**怎么用**：分别进 `额外信息渲染 → TNT渲染` 和 `额外信息渲染 → 苦力怕渲染`，把「引信渲染方式」选成「文本」或「进度条」。

- 默认是「不渲染」，也就是说这个功能装好后是静默的。
- 引信颜色会随时间由绿变红：TNT 满引信（80 tick）是绿的，快爆炸时是红的；苦力怕显示的是膨胀百分比。
- 「使用最高亮度」默认**开启**，这样即使在暗处、水里也能看清。
- 「仅Y轴旋转」开启后提示只绕 Y 轴转向你，关掉时会完整朝向相机。

## 画面修正与亮度

几个独立的小开关，都在 `额外信息渲染` 分组下：

**伽马覆盖**：不想装光影又想看清黑暗处时用。打开「启用」后拖动「伽马值」（默认 1.0，范围 0 ~ 30），数值越大画面越亮。

**总是渲染屏障 / 光源方块标记**：建筑或红石调试时会用屏障、光源方块做占位，原版看不见它们。打开对应开关后，原本标记在屏障 / 光源方块上的显示效果会正常显示出来。

**禁用文本混淆渲染**：有些服务器会用 `§k` 做乱码特效，开启后这类文本按键名原样显示，方便看清内容。

**禁用侧边计分板渲染**：不想让侧边计分板挡住画面时开启。数据仍然会同步，只是不画出来。

**使用兼容 Iris 着色器的渲染管线**：开着 Iris 光影时，本模组绘制的纹理（聊天气泡、引信进度条）可能出现异常，开启这一项会改用兼容渲染管线。**推荐把它和 Iris 光影开关绑成同一个快捷键**，这样光影和管线同步切换。

## 配置项速查

### 手持物品信息

| 界面位置 | 配置键 | 默认值 | 说明 |
|---|---|---|---|
| 手持物品信息 → 启用 | `render_info_addon.held_item.enable` | 关闭 | 接管原版手持物品信息渲染 |
| 渲染位置偏移 | `...held_item.offset` | `(0, 0)` | 范围 `-200 ~ 200` |
| 行距 | `...held_item.spacing` | `1` | 范围 `0 ~ 10` |
| 渲染阴影 | `...held_item.shadow` | 开启 | 文本是否带阴影 |
| 文本背景颜色 | `...held_item.text_background` | 透明 | 每行文本的背景色 |
| 背景颜色 | `...held_item.overall_background` | 透明 | 整体背景色 |
