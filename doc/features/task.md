# 任务管理器

任务就是「到点自动帮你做一件事」：发一条消息、发一条指令、跑一段脚本。可以只执行一次，也可以按周期反复执行；可以手动点一下执行，也可以绑一个快捷键随时触发。

**什么时候用**：挂机时定时喊话、进服务器自动发一条欢迎指令、按一个键连续完成一串操作（例如连续使用物品、按固定节奏移动）——最后这类靠脚本任务实现。

入口：**H + S → 任务管理器**，界面分「任务列表」「运行中的任务」「设置」三页。

---

## 新建并执行一个任务

1. 在「任务列表」页点工具栏的「新建任务」。
2. 填**任务名称**，选一个**任务图标**（列表和轮盘里显示的就是这个物品的图标，默认是成书）。
3. 设置执行节奏：
   - **任务延迟**：第一次执行前需要经过的 tick 数。注意 `0` 和 `1` 的效果一样（都是下一个 tick 就执行），差异从 `2` 开始。
   - **任务周期**：第一次执行之后每隔多少 tick 再执行一次（`1` 表示每个 tick 都执行）。延迟只在第一次生效，此后完全由周期决定。
   - **任务次数**：总共执行几次（默认 1 次，即只执行一次）。
   - **执行时间**：在客户端 Tick 的开始还是结束阶段执行。Tick 开始早于原版逻辑，Tick 结束晚于原版逻辑。
4. 选**执行器类型**并填写内容（见下一节）。
5. 保存。回到列表后：
   - 点行内的播放按钮 → 立即执行一次；
   - 给行内的按键控件录一个快捷键 → 之后按键即可执行，按键列表里会显示成「任务管理器 → 任务名」；
   - 长按行首的手柄可以拖动排序；
   - 不想用了就点删除（会二次确认）。

**运行中的任务**页可以查看每个正在运行的任务实例、它的执行周期和剩余次数，也可以在这一页停止它。

> 注意：在任务列表里删除任务**不会**停止已经在运行的实例，要停止请到「运行中的任务」页操作。

## 三种执行器

| 类型 | 你填什么 | 效果 |
|---|---|---|
| **指令** | 一条指令，例如 `say 大家好` | 代替你在聊天栏发送；不以 `/` 开头会自动补上 |
| **消息** | 一段文字 | 原样作为聊天消息发送 |
| **脚本** | 一段 JEXL 脚本 | 执行脚本，适合需要判断条件、读写数据的场景 |

脚本执行器出错时不会崩溃，只会在屏幕上弹一条红色提示并把堆栈写进日志。按 tick 高频执行的任务如果一直报错，提示会反复弹出，调试时注意把周期调大一些。

脚本里可以拿到：

| 变量 / 命名空间 | 含义 |
|---|---|
| `common` | 脚本 API，例如 `common:sendMessage("hi")`、`common:toast("好了")` |
| `player` | 当前玩家（玩家为空时不会注入） |
| `task` | 本次调度到的任务实例 |
| `eventContext` | 事件上下文，**只有由事件订阅触发的脚本**才有 |

脚本能做什么、有哪些现成函数，见 [脚本](script.md)。

## 用轮盘快速执行任务

任务多了以后，一个个记快捷键不如做一个轮盘。在「设置」页给「快捷任务执行界面快捷键」录一个键，之后按下就弹出轮盘，所有任务按图标铺在扇区上。

| 操作 | 效果 |
|---|---|
| 左键点扇区 | 执行该任务并关闭界面 |
| 中键点扇区 | 删除该任务（需确认） |
| 右键点扇区 | 编辑该任务 |
| 右键点空选区 | 新建任务 |
| 右键点中心或环外 | 关闭界面 |

界面下半部常驻显示这行操作提示。轮盘的外观（内外圈渐变、边框、半径、间距、圆角、倾斜角度、图标缩放）都能在同一个设置页里调，默认值已经能正常使用；任务多的时候把「每页最大任务数量」（默认 8）调大，或用默认的分页。

---

## 「设置」页里的脚本公用库

「脚本公用库」里的内容会在**每次执行任何脚本之前**先执行一次，适合放经常要用的自定义函数，写一遍所有任务都能用。默认是空的。详见 [脚本公用库](script.md#脚本公用库)。

## 配置项速查

### 任务字段

| 界面位置 | 配置键 | 默认值 | 取值范围 |
|---|---|---|---|
| 任务名称 | `name` | 空 | 任意文本，支持 `&{...}` 内联样式 |
| 任务图标 | `icon` | 成书 | 任意已注册物品 |
| 任务延迟 | `setting.delay` | `0` | 单位 tick，`0 ~ 1141514` |
| 任务周期 | `setting.period` | `1` | 单位 tick，`1 ~ 1141514` |
| 任务次数 | `setting.times` | `1` | `1 ~ 1141514` |
| 执行时间 | `execute_on` | 客户端 Tick 开始 | 客户端Tick开始 / 客户端Tick结束 |
| 执行器类型 | `executor_type` | 脚本 | 指令 / 消息 / 脚本 |
| 执行器 | `executor` | 空 | 与类型对应的内容 |
| 快捷键 | `keybind` | 未绑定 | 绑定后显示为「任务管理器 → 任务名」 |

### 数据文件

任务保存在 `config/hiirosakura/data/task_manager.json`，顶层是 `config`（上面的设置）和 `tasks`（任务数组）。可以在游戏外直接备份或搬运这个文件；读取时单条任务解析失败只会跳过那一条并记日志。

> 任务管理器本身没有导入 / 导出按钮。想复用任务可以选择「自定义径向菜单」页的「从任务管理器导入任务」，见 [菜单与物品编辑](menu-and-editor.md#从任务管理器导入任务)。
